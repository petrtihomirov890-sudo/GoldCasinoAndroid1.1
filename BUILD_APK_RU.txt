КАК ПОЛУЧИТЬ ГОТОВЫЙ APK ЧЕРЕЗ GITHUB (БЕЗ ANDROID STUDIO)

1. Открой https://github.com и войди или создай бесплатный аккаунт.
2. Нажми + → New repository. Назови его GoldCasinoHelper, выбери Public или Private и нажми Create repository.
3. На странице репозитория нажми Add file → Upload files.
4. Распакуй этот ZIP на телефоне/компьютере и загрузи ВСЁ содержимое папки GoldCasinoAndroid в репозиторий. Важно: вместе с обычными файлами должна попасть скрытая папка .github/workflows/build-apk.yml. Если GitHub через браузер не показывает скрытые файлы, загрузи папку .github отдельно через GitHub web interface или используй компьютер.
5. Нажми Commit changes.
6. Открой вкладку Actions → Build Android APK. Если workflow ещё не запустился, нажми Run workflow → Run workflow.
7. Дождись зелёной галочки (обычно несколько минут), открой завершённый запуск. Внизу страницы, в разделе Artifacts, нажми GoldCasinoHelper-debug-apk.
8. Распакуй скачанный artifact ZIP. Внутри будет app-debug.apk. Перенеси его на Android, открой и подтверди установку. При запросе Android разреши установку неизвестных приложений для браузера/файлового менеджера, которым открываешь APK.

Если сборка завершится красным крестиком, открой её и пришли текст ошибки из шага Build debug APK.

Примечание: это debug APK для личной установки, не релиз для Google Play. Приложение — самостоятельный помощник и не вмешивается в Black Russia.
