GOLD CASINO HELPER — Android-проект

Автономный помощник с чёрно-золотым интерфейсом:
- подсказки по базовой стратегии блэкджека;
- вероятности сумм двух стандартных костей;
- анализ комбинаций пяти покерных карт;
- калькулятор ставок;
- настройка масштаба интерфейса;
- плавающая кнопка ♛ поверх других приложений.

Плавающая кнопка:
При первом запуске Android предложит разрешить «Показывать поверх других приложений».
Это разрешение нужно только для плавающего ярлыка. Кнопку можно перетаскивать;
нажатие открывает помощник, долгое нажатие убирает кнопку. Чтобы включить её снова,
запусти приложение ещё раз.

Важно:
Приложение не подключается к Black Russia, не читает экран игры, не меняет клиент,
не автоматизирует ставки и не гарантирует выигрыш. Плавающая кнопка — только ярлык
для быстрого открытия отдельного помощника. Проверь правила сервера насчёт оверлеев.

Как собрать APK:
1. Открой папку проекта в Android Studio.
2. Дождись Gradle Sync.
3. Выбери Build > Build APK(s).
4. APK будет в app/build/outputs/apk/debug/app-debug.apk.

Требования: JDK 17, Android SDK Platform 35, минимум Android 6.0 (API 23).
